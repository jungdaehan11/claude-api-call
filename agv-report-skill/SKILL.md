# AGV 일일 운행 보고서 작성 규칙

## 섹션 (반드시 이 순서)
1. 한 줄 요약
2. 운행 실적 (완료 건수, 실패 건수, 총 주행 거리)
3. 이상 사항 (시간순, 각 항목에 심각도 표시)
4. 조치 필요 항목

## 심각도 기준
- 🔴 높음: 충돌, 비상정지(E-stop), 위치 추정 실패
- 🟡 중간: 경로 계획 실패 후 재시도 성공, 배터리 20% 미만
- 🟢 낮음: 일시 대기, 경로 우회

## 작성 규칙
- 한국어, 짧고 사실 위주. 추측하지 말 것
- 로그에 없는 수치는 "기록 없음"으로 적을 것
- 조치 필요 항목은 담당자가 바로 할 수 있는 행동으로 적을 것
